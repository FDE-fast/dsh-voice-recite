# DSH-人声朗诵

把文字变成一段可以"表演"的人声：选音色、按时间轴定长、指定某个字拖音或加颤音，一次输出 WAV 与 MP3。

## 怎么用

1. **输入框**：聊天输入框上方（composer 工具位）的「🎙 人声朗诵」按钮，点开就是表单。
2. 填五项：
   - **文本** —— 要朗读的内容。
   - **音色** —— 下拉选择，默认「小艺 · 少女感」，另有温柔女声、小男孩、青年男声、方言、粤语、台湾国语。
   - **开始时间 / 截止时间** —— 单位秒，可带两位小数。**音频时长 = 截止 − 开始**，例如 5.14 与 8.13 得到 2.99 秒；表单里会实时显示算出来的时长。
   - **输出位置** —— 目录绝对路径，WAV 与 MP3 都写到这里。
   - **拖音 / 颤音文字** —— 填文本里出现过的一小段（例如「大」），再用两个滑杆调「拖音倍数」与「颤音深度」；留空则原速朗读。
3. 点「生成 WAV + MP3」，下方直接出现播放器和两个文件的完整路径。

也可以直接让 Agent 调用工具 `recite`，参数与表单一致：

```
recite({
  text: "老大，我摔倒了。",
  voice: "zh-CN-XiaoyiNeural",
  startTime: 5.14, endTime: 8.13,
  outputDir: "C:\\Users\\me\\Desktop\\临时",
  focusText: "大", elongate: 1.7, vibrato: 8
})
```

## 生成规则

- **时长**：先合成，再按词边界把指定文字局部拉长、加颤音，最后整体微调到正好 `截止 − 开始` 秒（WAV 精确到采样点：2.99 秒 = 71760 个采样 @24 kHz）。
- **MP3**：MP3 以帧为单位（32 kHz 下每帧 36 ms），所以 MP3 时长只能取最近的一帧网格；2.99 秒的目标会得到 2.988 秒（差 2 ms）。WAV 始终是精确值。
- **拖音**：对该文字所在区间做变速不变调（WSOLA）拉伸，默认 1.6 倍，界面可调 1–2.5 倍。
- **颤音**：对该区间做周期性音高摆动，单位音分，6–15 音分比较自然。

## 依赖与限制

- 合成走微软 Edge 神经语音服务，**需要联网**；离线时生成会失败并返回错误原因。
- 引擎用 Python 运行（随插件携带 edge-tts / miniaudio / lameenc 依赖）。默认自动找 Harness 自带运行时 `~/.dsh/dsh-runtimes/*/dependencies/python`；也可以在插件 `config` 里写 `pythonPath` 覆盖。
- MP3 采样率固定 32 kHz 单声道 128 kbps；WAV 为 24 kHz 单声道 16 bit。
- 拖音/颤音只能作用于文本中存在的一段连续文字；找不到时按原速生成，并在结果里说明。
